# Security Policy

## Supported Versions

Security fixes are provided for the latest `main` branch and the latest tagged release.

## Reporting a Vulnerability

If you find a security issue (token leakage, unsafe file handling, command injection, dependency vulnerability):

1. Prefer private reporting through GitHub Security Advisories.
2. If private reporting is unavailable, open a GitHub issue and avoid posting secrets or exploit details.
3. Include reproduction steps, affected version/commit, and impact scope.

The project will acknowledge reports and provide remediation updates in a reasonable timeframe.
